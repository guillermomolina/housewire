# Development environment

This project uses the Python virtual environment at `.venv`.

Always use the project's virtual environment when running Python commands.

Examples:

- Python: `.venv/bin/python`
- Pytest: `.venv/bin/pytest`
- Pip: `.venv/bin/pip`

Do not use the system Python or system-installed Python tools.

When running tests, use `.venv/bin/pytest` unless the project specifies a more specific test command.
